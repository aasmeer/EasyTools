What is this tool?

The EasyTools Split PDF tool extracts selected pages into a new PDF. It is useful when only a chapter, receipt or supporting section of a larger document needs to be shared. Enter individual page numbers, ranges or a combination separated by commas. The page numbers refer to positions in the uploaded PDF, which can differ from numbers printed on the pages themselves. Keep the original document so the extracted file remains a delivery copy rather than your only version of the source.

Features

  • Upload a readable PDF and specify which pages belong in the output.
  • Use single page numbers or ranges in a comma-separated expression.
  • Create one new PDF containing the selected pages.
  • Download the extracted document without manually printing each page to a separate file.

Benefits

Sharing only the relevant section can make a document easier to review and avoid sending unnecessary pages. For example, extracting a few pages of instructions lets a recipient focus on the part that applies to their task. Check that the selection still includes enough context, such as titles, legends or continuation pages, to make sense independently. Removing surrounding pages can unintentionally leave an unexplained table or a paragraph that begins halfway through an argument.

How to use

  1. Upload the PDF and identify the source page positions you want.
  2. Enter an expression such as 1,3-5 to request page 1 and pages 3 through 5.
  3. Select Split PDF and wait for the extracted document to be generated.
  4. Download and open the new PDF, checking that every required page and its context are present.

Examples and limitations

A cover sheet or contents page can shift the relationship between PDF positions and printed numbering. If the printed page labelled '1' is the third page in the file, use the file position when selecting it. Review the result instead of assuming the printed number controls extraction. A malformed range or a page beyond the end of the document should be corrected before retrying. File and page limits also apply to browser processing.

Frequently asked questions

How do I request several separate pages?

Enter their page positions separated by commas, such as 2,5,8. You can combine single pages with ranges, such as 2,5-8, when the selected material contains both isolated and consecutive pages.

Does a range include both end pages?

A range such as 3-5 requests pages 3, 4 and 5. Check that both endpoints exist in the uploaded document and use the supported ascending range format.

Will I receive a separate file for every page?

This workflow creates a new PDF containing the selected pages. It is not a batch export that automatically creates an individual PDF for every original page.

Can I use a password-protected PDF?

The interface does not provide a password-unlocking workflow. If the file cannot be read, use a readable source copy that you are authorised to process rather than assuming extraction removes protection.

Are signatures or document-level features guaranteed to survive?

No. Creating a new document is not equivalent to preserving every source feature or digital signature. Inspect the extracted file and keep the original when those features or their verification matter.
