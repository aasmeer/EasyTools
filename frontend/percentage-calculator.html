What is this tool?

The EasyTools Percentage Calculator answers three common percentage questions: finding a percentage of a number, finding what percentage one number is of another, and measuring percentage change. These questions use different formulas, so choosing the correct mode is as important as entering the numbers accurately. The tool is useful for checking examples, comparing quantities and understanding changes between two values. It reports arithmetic results without deciding what those results mean for a particular financial, scientific or business context.

Features

  • Use X% of Number to calculate a selected share of a total.
  • Use What Percent? to compare a first number with a second number.
  • Use % Change to measure a new value against its original baseline.
  • Switch between labelled modes and calculate a result for each type of question.

Benefits

Clear mode choices help prevent a common mistake: using the wrong denominator. If 50 items out of 200 meet a condition, the share is 25%, because 200 is the whole. If a value rises from 100 to 125, the change is also 25%, but the calculation uses the original 100 as its baseline. The same displayed percentage can therefore describe different relationships. Write down what the two inputs represent before calculating a more complicated comparison.

How to use

  1. Choose the mode that matches the question you want to answer.
  2. Enter the percentage and number, the part and whole, or the original and new values.
  3. Select the Calculate button in the active mode.
  4. Read the result alongside the input labels and check that you used the intended baseline.

Examples and limitations

The formulas are percentage × number ÷ 100, first number ÷ second number × 100, and (new − original) ÷ original × 100. A zero denominator makes the latter two formulas undefined. Also distinguish percentage points from percentage change: moving from 20% to 25% is a five-percentage-point increase, while the relative increase against 20 is 25%. The tool's percentage-change mode calculates the relative comparison.

Frequently asked questions

How do I calculate 20% of 500?

Choose X% of Number, enter 20 as the percentage and 500 as the number. The result is 100. This finds a share of the total rather than an increase added to it.

Which value is the whole in What Percent?

The second number is the denominator, or whole. Entering 50 and 200 asks what percentage 50 represents of 200. Reversing the values asks a different question and produces a different result.

What does a negative percentage change mean?

For a positive starting value, a negative result indicates that the new value is lower. Check the original and new fields before interpreting the sign, particularly if the inputs themselves include negative values.

Can percentage change be calculated from zero?

Not with this relative-change formula, because it divides by the original value. A move from zero may be described as an absolute difference instead, but there is no finite percentage result under that formula.

Why do rounded results differ slightly from my manual calculation?

The interface formats the output to a limited number of decimal places. Keep the original inputs when doing subsequent calculations rather than repeatedly calculating from rounded displayed figures.
